Tool-writing caution:
functions.exec runs JS. Nested heredoc content in a normal JS string can consume
PHP namespace backslashes or break on quotes. A reliable pattern uses cmd:String.raw
with OUTER backticks, writes section-sign characters instead of inner JS template
backticks, and currency-sign characters instead of template interpolation dollars.
A final Python pass replaces those placeholders. Never accidentally interpolate
generated-code template expressions in the tool's own JavaScript execution.
