Paraphrased browser contract: Fetch defaults credentials to same-origin. A request
to a different origin needs credentials: "include" to opt into sending eligible
cookies. This does not override cookie SameSite, Secure, domain, third-party-cookie
restrictions or server CORS authorization. The question explicitly assumes these
other requirements are satisfied. No real browser cookie exchange is claimed by
this documentation check.
